# Vibe VS Code v1.135.0-vibe.1

首个 Vibe VS Code 发布版:Linux x64 的 Web 工作台加远端服务,自带 Node 与依赖,面向单管理员的托管部署。

## 本版内容 / Highlights

- **登录鉴权**([#15](https://github.com/ActivePeter/vibe-vscode/pull/15)):所有 HTTP 与 WebSocket 请求先经 Caddy `forward_auth` 通过登录才能到达 VS Code 路由。首个注册者成为唯一管理员,之后关闭注册;会话持久、滑动续期;全屏中英文登录页;Workbench 的 Accounts 菜单提供退出入口。设计见[全屏登录与实例认证](../../vibe_vscode_doc/design/login_authentication.md)。
- **启动资源缓存**([#14](https://github.com/ActivePeter/vibe-vscode/pull/14)):Workbench 核心资源按 256 KiB 分块、sha256 命名、gzip 预压缩,首次加载后存入浏览器 CacheStorage,再次打开不再下载;中断可续传,损坏块自动修复。设计见[页面加载缓存](../../vibe_vscode_doc/design/page_load_cache.md)。
- **发布流程**:打 `v*` tag 触发校验、打包与草稿 release;本文案随仓库版本管理。

## 升级须知 / Upgrade notes

- 这是第一个版本,没有从旧版本升级的路径。全新安装按下方链接操作。
- 必须配置 `VIBE_VSCODE_PUBLIC_ORIGIN` 为浏览器地址栏里的 HTTPS 源(含非默认端口);鉴权状态目录 `<state-root>/auth` 需在升级间保留,其中的 SQLite 数据库与签名 secret 丢失会导致所有会话失效并需要重新注册。
- Caddy 需单独安装,使用包内 `resources/server/vibe-vscode/` 的 Caddyfile 与 systemd 模板;公开端口只由 Caddy 监听,后端只在私有 Unix socket 上。
- 首次打开地址的人即成为管理员,请在创建账号前限制访问。

## 安装 / Install

按 [Releases and installation](../release.md) 下载 `vibe-vscode-server-v1.135.0-vibe.1-linux-x64.tar.gz`,校验 `.sha256`,解包到独立目录并切换 `current`。

## 已知问题 / Known issues

- 只提供 Linux x64。
- 安装了简体中文语言包时,Accounts 菜单里的 "Sign Out" 暂显示英文;登录、注册、退出页面本身是双语。
- 首次加载缓存分块需要安全上下文(HTTPS 或 localhost)以及浏览器的 `DecompressionStream` 与 `crypto.subtle`;不满足时启动页会给出说明。
